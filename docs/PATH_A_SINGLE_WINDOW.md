# 路径 A：单窗口全流程

## 适用条件

Bot 本身具备结构化分析、文件读写、Python 执行、实时来源表读取，以及调用私有 runner/auditor 的能力。Bot 不直接写 COS 或飞书。

## 执行顺序

1. 固定发布提交、发布 ZIP SHA、规则 SHA 和执行编号；
2. 从来源表全分页建立不可变快照，不使用旧队列代替实时来源；
3. 候选集 = 当日新增 + 最新批次 + 所有历史未终态，已终态且读回有效的记录幂等跳过；
4. 对每条记录核对来源身份、附件 SHA、录屏名称和账号，错配只隔离本条；
5. 在当前窗口生成结构化边界、决策、人看字段和逐字证据；
6. 运行人看字段硬门禁；失败只返工对应字段；
7. 生成确定性 WritePlan，锁定 analysis SHA、record_id、generation 和幂等键；
8. 私有 runner 按存储→案例库→案例匹配→源表顺序写入，每一步写后读回；
9. 独立 auditor 全分页复核四方对象、SHA、关联和表内可读内容；
10. 只对 ReworkOrder 指定的记录和阶段局部返工，直到全体进入合法终态。

## 不允许

- 一个记录失败就停止整批；
- Bot 直接拿飞书/COS 密钥写表；
- 先写源表完成状态再补案例库或案例匹配；
- 把 review 当 accept、替真人签署、把 reject 当失败反复重跑；
- 用日报、群消息、HTTP 200、线程更新时间或队列状态证明完成。
