# 公开发布边界

公开仓库只包含合同、执行框架、门禁、匿名夹具、示例配置和操作说明。它不能独立访问真实业务系统。

禁止进入公开仓库：

- 真实飞书 app token、table_id、record_id、webhook；
- COS 凭据值、桶名、地域、前缀和真实对象键；
- cookie、登录态、浏览器 profile、用户名、密码；
- 真实直播稿、案例文本、业务快照、运行回执和本机绝对路径；
- 私有 runner/auditor 适配器实现与任何绕过权限的入口。

允许进入公开仓库：

- 环境变量名称和布尔 capability profile；
- 匿名 record/source 示例；
- 协议、状态机、写入顺序、幂等与读回合同；
- 人看字段、证据和会话清理门禁；
- 发布扫描器、离线测试及无密发布 ZIP。

生产接入必须由用户把公开框架部署到私有环境，再通过最小授权注入适配器。Bot 不得要求用户在对话里展示密钥。
